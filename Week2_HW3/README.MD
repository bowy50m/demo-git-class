# Varis Lab Flexbox Bootcamp Landing Page

Landing Page สำหรับประชาสัมพันธ์คอร์ส Full-Stack Bootcamp — AI Edition ของ Varis Lab

โปรเจกต์นี้จัดทำขึ้นเพื่อฝึกการเขียน Semantic HTML การจัด Layout ด้วย Flexbox และการออกแบบหน้าเว็บไซต์แบบ Responsive

## ภาพรวมโปรเจกต์

หน้าเว็บไซต์ประกอบด้วยส่วนสำคัญดังนี้:

* Navigation Bar
* Hero Section
* Bootcamp Information Card
* Features Section
* Pricing Section
* Curriculum Section
* Target Audience Section
* Footer

## เทคโนโลยีที่ใช้

* HTML5
* CSS3
* Flexbox
* Responsive Web Design

## โครงสร้างไฟล์

```text
varis-lab-landing-page/
├── index.html
├── style.css
└── README.md
```

## วิธีเปิดใช้งาน

1. ดาวน์โหลดหรือ Clone โปรเจกต์
2. เปิดโฟลเดอร์โปรเจกต์
3. เปิดไฟล์ `index.html` ด้วย Web Browser

หรือใช้ส่วนเสริม Live Server ใน Visual Studio Code:

1. ติดตั้งส่วนเสริม Live Server
2. คลิกขวาที่ไฟล์ `index.html`
3. เลือก `Open with Live Server`

## เนื้อหาที่ฝึกในโปรเจกต์

### Semantic HTML

ใช้ HTML Elements ตามหน้าที่ของเนื้อหา เช่น:

* `<header>`
* `<nav>`
* `<main>`
* `<section>`
* `<article>`
* `<aside>`
* `<footer>`

### Flexbox

ใช้ Flexbox สำหรับจัดวาง:

* Navigation Bar
* Hero Section
* Feature Cards
* Pricing Cards
* Curriculum Cards
* Target Audience Cards

### Responsive Layout

ปรับหน้าเว็บไซต์ให้รองรับอุปกรณ์หลายขนาด เช่น:

* Desktop
* Tablet
* Mobile

## จุดประสงค์ของโปรเจกต์

* ฝึกสร้างหน้า Landing Page จากโครงสร้างจริง
* ฝึกใช้ Semantic HTML
* ฝึกจัด Layout ด้วย Flexbox
* ฝึกออกแบบ Card Components
* ฝึกสร้าง Responsive Website
* ฝึกแยก HTML และ CSS ออกจากกัน
