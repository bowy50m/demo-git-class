ตอบคำถามสั้น ๆ:

Flexbox กับ Grid ต่างกันอย่างไร?
-Flexbox ใช้จัดวางองค์ประกอบแบบ 1 มิติ คือจัดเป็นแนวนอนหรือแนวตั้ง
-Grid ใช้จัดวางองค์ประกอบแบบ 2 มิติ คือจัดได้ทั้งแถวและคอลัมน์ในเวลาเดียวกัน

ทำไม Curriculum Section เหมาะกับ Grid?
-เพราะมีจำนวน 6 ช่อง ทำให้เหมาะกับการใช้งาน Grid 

grid-template-columns ใช้ทำอะไร?
-ใช้กำหนดจำนวนและขนาดของคอลัมน์ใน Grid

UI polish ที่คุณปรับมีอะไรบ้าง?
-เพิ่ม hover เพื่อให้กรอบหรือสีของข้อความเปลี่ยนเมื่อวางเมาส์

การจัด CSS เป็นหมวดช่วยอย่างไร?
-ทำให้สามารถดูการทำงานได้ง่ายและรวดเร็วมากขึ้น งานเป็นระเบียบมากขึ้น 

Git กับ GitHub ต่างกันอย่างไร?
-Git คือ การเก็บเวอร์ชั่นอัพเดทในเครื่อง 
-GitHub คือ การแชร์เวอร์ชั่นออนไลน์ โดยสามารถทำงานร่วมกับDeveloper ท่านอื่นๆได้ 

Commit คืออะไร?
-การบันทึกการเปลี่ยนแปลงของไฟล์ไว้ใน Git พร้อมข้อความอธิบายว่าแก้ไขอะไร
